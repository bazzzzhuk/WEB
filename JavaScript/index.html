Introduction JavaScript

JavaScript ― Это интерпретируемый язык программирования общего назначения с динамической типизацией данных.

Интерпретируемый ― значит, что программа выполняется в исходном виде, т.е. исходный код не преобразуется в машинный или промежуточный код. В связи с этим ошибки на этапе компиляции и компоновки отсутствуют, только ошибки на этапе выполнения. Интерпретатор JavaScript может быть установлен в любую ОС как семейство виндовс, так и семейство Юникс.
Это даёт хорошую переносимость кода или кроссплатформенность.
JavaScript также иногда используют для разработки мобильных приложений под/для андроид.
JavaScript также часто используют в тестировании для написания скриптов, но несмотря на всё это чаще всего JavaScript используется для разработки веб-приложений, а именно фронт-энд части веб-приложения. И следовательно самым основным и распостраненным интерпретатором JavaScript является самый обычный браузер.

Динамическая типизация ― говорит о том, что тип переменных и констант определяется во время присваивания по типу значения справа (r-value); Это в свою очередь означает то, что у переменной нет как такового постоянного типа данных. Например в переменную в которой хранится число можно записать строку и при записи она изменит тип. Это достигается благодаря тому, что абсолютно все типы являются объектами, а также благодаря полиморфизму.

Переменные и константы

var
Объявляет глобальную переменную несмотря на область видимости в которой объявлена. Если записать значение в несуществующую переменную, то это не вызовет ошибку - это будет аналогично ключевому слову "var"
let
Объявляет локальную переменную только для той области видимости в которой она используется.
const
Объявляет константу. Константы могут быть только локальными.
